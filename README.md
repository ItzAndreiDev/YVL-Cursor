# YVL-Cursor
Took the time to cook up this cursor pack with the YVL hand gesture (using Ken Carson's hand I took from Google). Idea originates from an Instagram tutorial, but there was no link to download the cursor so I tried my best to recreate it.

# How to use
(For Windows, haven't made a Linux or MacOS version yet, but it might be the same)
Go into Settings > Accesiblity (on the left) > Mouse pointer and touch > Customize pointer image
There, import the following:
Normal Select = normal_select.cur
Text Select, Link Select = text_link_select.cur
Busy, Working in background = busy_workinginbackground.cur
